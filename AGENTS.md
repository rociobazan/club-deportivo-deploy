# Instrucciones para agentes de IA

Valen para cualquier agente que trabaje en este repositorio (Claude Code, Codex, Cursor,
GitHub Copilot, Gemini CLI u otro).

## Sin atribución a agentes en GitHub

Los commits, PRs e issues de este repo figuran solo a nombre de integrantes del equipo: la
lista de *Contributors* es parte de la evaluación.

- Nunca agregues trailers que nombren a un agente o a su empresa (`Co-Authored-By: Claude …`,
  `Co-authored-by: Copilot …`, `Generated-by:` o similares).
- Nunca agregues pies ni links del tipo "Generated with …" o "Claude-Session: …" en commits,
  descripciones de PR, issues o comentarios.
- No cambies `user.name` ni `user.email` de git.
- Si tu herramienta agrega atribución por su cuenta y no podés desactivarla, avisá en vez de
  commitear.
